หน้าที่ 1
สคริป : กราบเรียนท่านคณะกรรมการและอาจารย์ที่ปรึกษา ผศ. จตุภูมิ จวนชัยภูมิ ทุกท่านครับ พวกเรากลุ่มโครงงาน TradeSensei ระบบวิเคราะห์และพยากรณ์ราคาหุ้นอัจฉริยะด้วยปัญญาประดิษฐ์ กระผมนายณัฐกานต์ ทาทอง และนายธีปกรณ์ ทิพมนต์ นักศึกษาสาขาวิชาเทคโนโลยีสารสนเทศ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น วันนี้พวกเรามีความยินดีเป็นอย่างยิ่งที่จะนำเสนอแพลตฟอร์มช่วยตัดสินใจลงทุนที่ผสานพลังของ Machine Learning, NLP และ Generative AI เข้าด้วยกันครับ

หน้าที่ 2
สคริป : จุดเริ่มต้นของโครงงานนี้ เกิดจากการที่เราพบปัญหาสำคัญของนักลงทุน 3 ประการครับ ประการแรก ข้อมูลกระจัดกระจาย นักลงทุนต้องเปิดหลายแท็บ สลับหน้าจอดูราคากราฟจากเว็บหนึ่ง ไปอ่านข่าวจากอีกเว็บหนึ่ง ทำให้เสียเวลาและจับต้นชนปลายยาก ประการที่สอง ข้อมูลข่าวสารล้นหลาม ในแต่ละวันมีข่าวสารมหาศาล แต่นักลงทุนยากที่จะประเมินได้อย่างรวดเร็วว่าข่าวไหนส่งผลต่อราคาในเชิงบวกหรือเชิงลบ และประการที่สาม ขาดเครื่องมือช่วยประเมินราคาล่วงหน้าและทดสอบกลยุทธ์ย้อนหลัง เครื่องมือระดับมืออาชีพส่วนใหญ่มีราคาสูง ใช้งานยาก และไม่มีระบบประเมินความเสี่ยงล่วงหน้าแบบเรียลไทม์ครับ

หน้าที่ 3
สคริป : จากปัญหาข้างต้น เราจึงกำหนดวัตถุประสงค์หลักของระบบไว้ 3 ประการ ได้แก่ 1. พัฒนาระบบรวบรวมข้อมูลราคาหุ้นย้อนหลังและข่าวสารทางการเงินแบบอัตโนมัติมาไว้ในจุดเดียว 2. ประยุกต์ใช้ Machine Learning ในการพยากรณ์แนวโน้มราคาหุ้นล่วงหน้า 7 วัน พร้อมกรอบความเชื่อมั่นทางสถิติ และ 3. พัฒนาระบบประเมินอารมณ์ข่าวด้วย NLP พร้อมทั้ง AI Copilot ที่ช่วยสรุปข้อมูลและตอบคำถามเชิงลึกแก่นักลงทุนได้อย่างตรงไปตรงมาและปลอดภัยครับ

หน้าที่ 4
สคริป : ในส่วนถัดไป จะเป็นรายละเอียดของสถาปัตยกรรมระบบและชุดเทคโนโลยีที่พวกเราเลือกใช้ในการพัฒนาครับ

หน้าที่ 5
สคริป : สำหรับฝั่ง Frontend เราเลือกใช้ HTML5, CSS3 และ JavaScript โดยเน้นการออกแบบ Responsive Dark Mode ที่ทันสมัย โหลดเร็ว น้ำหนักเบา และผสานการวาดกราฟแท่งเทียนเชิงโต้ตอบที่ทำงานได้อย่างลื่นไหลโดยไม่ต้องพึ่งพา Framework ขนาดใหญ่ครับ

หน้าที่ 6
สคริป : ในส่วนของ Backend เราเลือกใช้ Python ร่วมกับ Flask Framework เพื่อสร้าง RESTful API เนื่องจากภาษา Python เป็นศูนย์กลางของไลบรารีด้าน Data Science และ AI ทำให้การเชื่อมต่อ Data Pipeline เข้าสู่โมเดลทำได้อย่างมีประสิทธิภาพและรวดเร็วครับ

หน้าที่ 7
สคริป : AI ตัวแรกคือ Facebook Prophet พัฒนาโดย Meta ครับ เราเลือกใช้ทำนายราคา 7 วัน เนื่องจากใช้โครงสร้าง Additive Regression ที่แยกแนวโน้ม ฤดูกาลรายสัปดาห์และรายปี รวมถึงจัดการกับวันหยุดทำการของตลาดหลักทรัพย์ได้โดยตรง ที่สำคัญคือให้ค่ากรอบความเชื่อมั่น 90% ออกมาด้วย ทำให้นักลงทุนมองเห็นขอบเขตความเสี่ยงที่ชัดเจนครับ

หน้าที่ 8
สคริป : AI ตัวที่สองคือ NLP Sentiment Analysis โดยใช้ TextBlob ทำหน้าที่สกัดข้อความจากพาดหัวและเนื้อหาข่าวหุ้น เพื่อคำนวณหาค่า Polarity Score ระหว่าง -1 ถึง +1 และจัดหมวดหมู่ออกเป็น ข่าวเชิงบวก ข่าวทั่วไป และข่าวเชิงลบ ช่วยแปลงข้อมูลเชิงคุณภาพให้กลายเป็นคะแนนเชิงปริมาณที่นำไปใช้ประกอบการวิเคราะห์ได้ทันทีครับ

หน้าที่ 9
สคริป : AI ตัวที่สามคือ Google Gemini นำมาพัฒนาเป็น Sensei Copilot ผู้ช่วยตอบคำถามเชิงลึกและย่อยศัพท์เทคนิคการเงินให้เข้าใจง่าย โดยทำงานแบบเข้าใจบริบทราคา ข่าว และผลการทำนาย และมี Guardrails ปฏิเสธการชี้แนะซื้อขายโดยตรง เพื่อให้เป็นไปตามหลักจรรยาบรรณทางการเงินครับ

หน้าที่ 10
สคริป : ในด้านฐานข้อมูลและโครงสร้างพื้นฐาน เราใช้ PostgreSQL ในการจัดเก็บข้อมูลราคา ข่าวสาร ผู้ใช้ และ System Logs ทั้งหมด พร้อมบรรจุระบบลงใน Docker Container เพื่อให้สะดวกต่อการ Deploy และการขยายระบบในอนาคตครับ

หน้าที่ 11
สคริป : ถัดมาเป็นหน้าจอจริงของระบบครับ นี่คือหน้า Interactive Stock Dashboard ด้านบนแสดงราคาล่าสุด การเปลี่ยนแปลง และสถานะตลาดแบบ Live ตัวกราฟเป็นแท่งเทียนมาตรฐาน มีเส้นค่าเฉลี่ย SMA 20 และ SMA 50 วัน แถบ Volume และปุ่มเลือกช่วงเวลาตั้งแต่ 1 วันจนถึง 2 ปี เพื่อให้นักลงทุนวิเคราะห์พฤติกรรมราคาได้อย่างครอบคลุมครับ

หน้าที่ 12
สคริป : เมื่อกดปุ่มทำนาย ระบบจะประมวลผลโมเดล Prophet ทันที แสดงผลเป็นเส้นประสีม่วงล่วงหน้า 7 วัน พร้อมแถบกรอบสีฟ้าซึ่งเป็นกรอบความเชื่อมั่น 90% และระบบยังทำการประเมินผลย้อนหลัง 14 วันแบบ Real-time โดยแสดงค่าความแม่นยำ Accuracy สูงถึง 96.12% และค่าความคลาดเคลื่อนเฉลี่ย MAE เพียง 1.619 ทำให้นักลงทุนประเมินความน่าเชื่อถือของโมเดลได้ทันทีครับ

หน้าที่ 13
สคริป : หลายท่านอาจสงสัยว่า ในเมื่อเรามี Machine Learning ทำไมเราถึงเลือกทำนายล่วงหน้าแค่ 7 วัน ไม่ทำนาย 1 เดือน หรือ 3 เดือน คำตอบอยู่ในสไลด์ถัดไปครับ

หน้าที่ 14
สคริป : เหตุผลทางสถิติและการเงินคือเรื่อง Error Accumulation และ Cone of Uncertainty ครับ ตลาดหุ้นมีความแปรปรวนสูง เมื่อทำนายไกลออกไป ความผิดพลาดจะสะสมจนกรอบความไม่แน่นอนบานออกเป็นรูปกรวย การทำนาย 7 วัน กรอบความเชื่อมั่นจะยังแคบและรัดกุม เช่น PTT แกว่งตัวระหว่าง 33.50 ถึง 35.50 บาท ซึ่งนำไปใช้วางแผนจุด Take Profit หรือ Stop Loss ได้จริง แต่หากทำนาย 30 วัน กรอบจะกว้างมากจนไร้ประโยชน์ในการตัดสินใจ 7 วันจึงเป็นจุดสมดุลที่ดีที่สุดครับ

หน้าที่ 15
สคริป : ในส่วนของข่าวสาร ระบบจะดึงข่าวล่าสุดของหุ้นตัวนั้นๆ จากสำนักข่าวการเงินชั้นนำแบบอัตโนมัติ และส่งเข้า NLP เพื่อประเมินอารมณ์ทันที โดยแสดงเป็นป้ายสีชัดเจน สีเขียวคือข่าวบวก สีเทาคือข่าวทั่วไป และสีแดงคือข่าวลบ พร้อมคะแนน Polarity ช่วยให้นักลงทุนทราบทิศทางกระแสข่าวได้ในไม่กี่วินาทีครับ

หน้าที่ 16
สคริป : แถบ Deep Analysis เป็นการประมวลผลขั้นสูง โดยนำข้อมูลราคาในอดีต ผลทำนาย 7 วัน และกระแสอารมณ์ข่าวมารวมเข้าด้วยกัน เพื่อสรุปเป็นภาพรวมชิ้นเดียว ทั้งสัดส่วนอารมณ์ตลาด แนวโน้มขาขึ้นหรือขาลง และเปอร์เซ็นต์คาดการณ์การเปลี่ยนแปลงราคา ช่วยย่นระยะเวลาในการวิเคราะห์ข้อมูลของนักลงทุนครับ

หน้าที่ 17
สคริป : สไลด์นี้แสดงโฟลว์การทำงานเบื้องหลัง เริ่มต้นจาก Data Scraper ดึงข้อมูลราคาและข่าวเข้าฐานข้อมูล PostgreSQL จากนั้นส่งข่าวไป TextBlob NLP วิเคราะห์คะแนน และส่งราคาเข้า Prophet AI พยากรณ์แนวโน้ม แล้วนำข้อมูลมารวมกันเพื่อส่งออกเป็นบทวิเคราะห์เชิงลึกแสดงบนหน้าจอแบบอัตโนมัติครับ

หน้าที่ 18
สคริป : ฟีเจอร์ Sensei Copilot แชทบอทอัจฉริยะ ออกแบบด้วยสถาปัตยกรรม RAG โดยดึงราคาจริง ผลทำนาย และข่าวล่าสุดของหุ้นที่ผู้ใช้กำลังดูอยู่ ไปเป็นบริบทให้ Gemini ผู้ใช้สามารถพิมพ์ถามคำถาม เช่น ทำไมแนวโน้มสัปดาห์นี้ถึงชี้ว่าขาขึ้น หรือให้อธิบายข่าวผลประกอบการ ระบบจะตอบกลับอย่างเข้าใจง่าย บันทึกประวัติการแชท และย้ำเตือนเรื่องความเสี่ยงเสมอครับ

หน้าที่ 19
สคริป : ฟีเจอร์ Time Machine เป็นระบบ Backtesting ที่ตอบโจทย์ว่า ถ้าในอดีตเรานำเงิน 10,000 บาทมาลงทุนในหุ้นตัวนี้ 6 เดือน วันนี้จะได้ผลตอบแทนเท่าไหร่ ระบบจะคำนวณกำไรขาดทุนตามราคาจริง แสดงผลเป็นจำนวนเงินและเปอร์เซ็นต์ พร้อมเปรียบเทียบกับดอกเบี้ยเงินฝากธนาคาร ช่วยให้นักลงทุนเข้าใจผลตอบแทนและความเสี่ยงได้อย่างเป็นรูปธรรมครับ

หน้าที่ 20
สคริป : ในส่วนของผู้ดูแลระบบ หน้านี้คือ System & Activity Logs จะคอยบันทึกการกระทำทุกอย่างในระบบ เช่น การเข้าสู่ระบบของผู้ใช้ การกดทำนายราคา หรือการสั่งรันโมเดล เพื่อความโปร่งใส ความปลอดภัย และช่วยให้สามารถตรวจสอบย้อนหลังได้ตลอดเวลาครับ

หน้าที่ 21
สคริป : หน้านี้เป็นหน้าจัดการหุ้นและสั่งงานระบบ ผู้ดูแลระบบสามารถเพิ่มหุ้นใหม่ ลบหุ้นที่ไม่ต้องการ และมีปุ่ม Action สั่งอัปเดตราคาล่าสุด ดึงข่าวสารใหม่ รวมถึงปุ่ม Batch Retrain เพื่อสั่งฝึกฝนโมเดล AI ใหม่ทั้งหมดได้ด้วยการคลิกเพียงครั้งเดียวครับ

หน้าที่ 22
สคริป : หน้าจัดการผู้ใช้งาน ผู้ดูแลระบบสามารถตรวจสอบรายชื่อผู้ใช้ กำหนดสิทธิ์ระดับ Admin หรือ Member รวมถึงแก้ไขหรือลบผู้ใช้ที่ไม่เหมาะสมออกจากระบบ เพื่อรักษาความปลอดภัยของแพลตฟอร์มครับ

หน้าที่ 23
สคริป : โดยสรุปแล้ว TradeSensei ประสบความสำเร็จในการพัฒนาเป็นแพลตฟอร์มช่วยวิเคราะห์และตัดสินใจลงทุนแบบครบวงจร รวมข้อมูลราคาและข่าวสาร ผสานพลัง AI ทั้ง Prophet ทำนาย 7 วัน, NLP วิเคราะห์อารมณ์ข่าว และ Copilot อธิบายเชิงลึก ควบคู่กับ Time Machine ที่ช่วยให้นักลงทุนตัดสินใจบนข้อมูลจริง แทนการใช้อารมณ์ความรู้สึกครับ

หน้าที่ 24
สคริป : กลุ่มของพวกเราขอจบการนำเสนอโครงงาน TradeSensei ไว้แต่เพียงเท่านี้ ขอขอบพระคุณท่านคณะกรรมการทุกท่านเป็นอย่างสูงครับ หากมีข้อสงสัยหรือข้อเสนอแนะประการใด พวกเรายินดีตอบคำถามครับ ขอขอบพระคุณครับ
