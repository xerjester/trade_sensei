# กิตติกรรมประกาศ

ปริญญานิพนธ์ฉบับนี้สำเร็จลุล่วงได้ด้วยความกรุณาและความช่วยเหลือจากบุคคลหลายท่าน ผู้จัดทำขอกราบขอบพระคุณทุกท่านไว้ ณ โอกาสนี้

ขอกราบขอบพระคุณ**อาจารย์ที่ปรึกษาปริญญานิพนธ์** ที่ให้คำแนะนำ ชี้แนะแนวทาง และตรวจสอบแก้ไขข้อบกพร่องต่าง ๆ ตลอดจนให้กำลังใจในการดำเนินงานตลอดระยะเวลาการจัดทำปริญญานิพนธ์ฉบับนี้

ขอกราบขอบพระคุณ**คณาจารย์ประจำสาขาวิชา** ทุกท่านที่ได้ประสิทธิ์ประสาทวิชาความรู้ด้านวิทยาการคอมพิวเตอร์ วิศวกรรมซอฟต์แวร์ และปัญญาประดิษฐ์ ซึ่งเป็นรากฐานสำคัญในการพัฒนาระบบ TradeSensei ฉบับนี้

ขอขอบคุณ**เพื่อน ๆ และผู้ใช้งานที่ร่วมทดสอบระบบ** ที่สละเวลาทดลองใช้งาน ตรวจสอบข้อผิดพลาด และให้ข้อเสนอแนะอันเป็นประโยชน์ ทำให้ระบบมีความสมบูรณ์ยิ่งขึ้น

ขอกราบขอบพระคุณ**บิดา มารดา และครอบครัว** ที่ให้การสนับสนุน เป็นกำลังใจ และเป็นแรงผลักดันสำคัญตลอดการศึกษาและการจัดทำปริญญานิพนธ์ฉบับนี้

สุดท้ายนี้ คุณประโยชน์ใด ๆ อันเกิดจากปริญญานิพนธ์ฉบับนี้ ผู้จัดทำขอมอบเป็นเครื่องบูชาพระคุณ บิดา มารดา ครูบาอาจารย์ และผู้มีพระคุณทุกท่าน
