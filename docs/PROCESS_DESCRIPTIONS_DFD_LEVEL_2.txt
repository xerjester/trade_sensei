ID : 1.1
ชื่อกระบวนการ(Name) : ลงทะเบียนสมาชิกใหม่
ข้อมูลนำเข้า(Input data flow)
1. ข้อมูลการสมัครสมาชิก
ข้อมูลออก(Output data flow)
1. ข้อมูลบันทึกกิจกรรมความปลอดภัย
2. ข้อมูลบัญชีผู้ใช้ใหม่
3. สถานะผลการสมัครสมาชิก
4. ข้อความแจ้งเตือนสถานะระบบ
เริ่มกระบวนการ
รับ ข้อมูลการสมัครสมาชิก จากผู้ใช้งานทั่วไป
ตรวจสอบความถูกต้องของรูปแบบอีเมล รหัสผ่าน และตรวจสอบความซ้ำซ้อนในระบบ
ทำการเข้ารหัสความปลอดภัยของรหัสผ่าน (Password Hash)
ส่งออก ข้อมูลบัญชีผู้ใช้ใหม่ เพื่อจัดเก็บลงในแฟ้มข้อมูลผู้ใช้งาน
ส่งออก ข้อมูลบันทึกกิจกรรมความปลอดภัย ไปยังแฟ้มข้อมูลบันทึกระบบ
ส่งออก สถานะผลการสมัครสมาชิก และ ข้อความแจ้งเตือนสถานะระบบ แจ้งผลการลงทะเบียนแก่ผู้ใช้งาน
จบการทำงาน

ข้อมูลออก(Output data flow)
1. ข้อมูลสิทธิ์การเข้าใช้งาน
2. ข้อมูลโปรไฟล์ผู้ใช้งาน
3. ข้อความแจ้งเตือนสถานะระบบ
4. ข้อมูลบันทึกกิจกรรมความปลอดภัย
เริ่มกระบวนการ
รับ ข้อมูลการเข้าสู่ระบบ จากผู้ใช้งานทั่วไป
ดึง ข้อมูลบัญชีสำหรับตรวจสอบสิทธิ์ จากแฟ้มข้อมูลผู้ใช้งาน
ตรวจสอบความถูกต้องของอีเมลและรหัสผ่านที่เข้ารหัสไว้
กรณีข้อมูลถูกต้อง ออกโทเค็นยืนยันตัวตน และดึงข้อมูลส่วนตัวของผู้ใช้
ส่งออก ข้อมูลบันทึกกิจกรรมความปลอดภัย ไปยังแฟ้มข้อมูลบันทึกระบบ
ส่งออก ข้อมูลสิทธิ์การเข้าใช้งาน ข้อมูลโปรไฟล์ผู้ใช้งาน และ ข้อความแจ้งเตือนสถานะระบบ ไปยังผู้ใช้งาน

ID : 1.3
ชื่อกระบวนการ(Name) : เข้าสู่ระบบด้วยบริการภายนอก
ข้อมูลนำเข้า(Input data flow)
1. ข้อมูลยืนยันตัวตนผ่านบริการภายนอก
2. ข้อมูลบัญชีผู้ใช้งานจากบริการภายนอก
ข้อมูลออก(Output data flow)
1. ข้อมูลสิทธิ์การเข้าใช้งาน
2. ข้อมูลโปรไฟล์ผู้ใช้งาน
3. ข้อมูลบัญชีผู้ใช้ใหม่
4. ข้อมูลบันทึกกิจกรรมความปลอดภัย
5. คำขอตรวจสอบสิทธิ์การยืนยันตัวตน
เริ่มกระบวนการ
รับ ข้อมูลยืนยันตัวตนผ่านบริการภายนอก จากผู้ใช้งานทั่วไป
ส่งออก คำขอตรวจสอบสิทธิ์การยืนยันตัวตน ไปยังระบบบริการภายนอก (Google OAuth)
รับ ข้อมูลบัญชีผู้ใช้งานจากบริการภายนอก ที่ได้รับการยืนยันความถูกต้องกลับมา
ตรวจสอบว่ามีบัญชีผู้ใช้นี้ในระบบหรือไม่ หากยังไม่มีให้ส่งออก ข้อมูลบัญชีผู้ใช้ใหม่ ไปบันทึกในแฟ้มข้อมูลผู้ใช้งาน
ออกสิทธิ์การเข้าใช้งานและจัดเตรียมโปรไฟล์ผู้ใช้งาน
ส่งออก ข้อมูลบันทึกกิจกรรมความปลอดภัย ไปยังแฟ้มข้อมูลบันทึกระบบ
ส่งออก ข้อมูลสิทธิ์การเข้าใช้งาน และ ข้อมูลโปรไฟล์ผู้ใช้งาน ไปยังผู้ใช้งาน
จบการทำงาน

ID : 1.4
ชื่อกระบวนการ(Name) : กู้คืนรหัสผ่านด้วยรหัสยืนยัน
ข้อมูลนำเข้า(Input data flow)
1. ข้อมูลขอรหัสยืนยันการตั้งรหัสผ่านใหม่
2. ข้อมูลการตั้งรหัสผ่านใหม่
3. สถานะการจัดส่งอีเมล
4. ข้อมูลรหัสยืนยันสำหรับตรวจสอบ
ข้อมูลออก(Output data flow)
1. สถานะการส่งรหัสยืนยัน
2. สถานะการตั้งรหัสผ่านใหม่
3. ข้อความแจ้งเตือนสถานะระบบ
4. ข้อมูลบันทึกกิจกรรมความปลอดภัย
5. คำขอส่งรหัสยืนยันทางอีเมล
6. ข้อมูลรหัสยืนยันที่สร้างขึ้น
7. ข้อมูลรหัสผ่านใหม่ที่แก้ไข
เริ่มกระบวนการ
รับ ข้อมูลขอรหัสยืนยันการตั้งรหัสผ่านใหม่ จากผู้ใช้งานทั่วไป
สุ่มสร้างรหัสยืนยันความปลอดภัย กำหนดเวลาหมดอายุ แล้วส่งออก ข้อมูลรหัสยืนยันที่สร้างขึ้น ไปบันทึกยังแฟ้มข้อมูลผู้ใช้งาน
ส่งออก คำขอส่งรหัสยืนยันทางอีเมล ไปยังระบบบริการภายนอก (อีเมล)
รับ สถานะการจัดส่งอีเมล และส่งออก สถานะการส่งรหัสยืนยัน แจ้งให้ผู้ใช้งานทราบ
เมื่อผู้ใช้ส่ง ข้อมูลการตั้งรหัสผ่านใหม่ พร้อมรหัสยืนยัน ให้ดึง ข้อมูลรหัสยืนยันสำหรับตรวจสอบ จากแฟ้มข้อมูลผู้ใช้งานมาตรวจสอบความถูกต้องและเวลาหมดอายุ
เมื่อรหัสถูกต้อง ทำการเข้ารหัสผ่านใหม่และส่งออก ข้อมูลรหัสผ่านใหม่ที่แก้ไข ไปปรับปรุงในแฟ้มข้อมูลผู้ใช้งาน
ส่งออก ข้อมูลบันทึกกิจกรรมความปลอดภัย ไปยังแฟ้มข้อมูลบันทึกระบบ
ส่งออก สถานะการตั้งรหัสผ่านใหม่ และ ข้อความแจ้งเตือนสถานะระบบ ไปยังผู้ใช้งาน
จบการทำงาน

ID : 1.5
ชื่อกระบวนการ(Name) : บริหารจัดการบัญชีผู้ใช้งาน
ข้อมูลนำเข้า(Input data flow)
1. คำสั่งค้นหาข้อมูลสมาชิก
2. คำสั่งปรับเปลี่ยนสิทธิ์ผู้ใช้งาน
3. คำสั่งลบบัญชีผู้ใช้งาน
4. คำสั่งเปลี่ยนรหัสผ่านบัญชีส่วนตัว
5. ข้อมูลสมาชิกทั้งหมดในระบบ
ข้อมูลออก(Output data flow)
1. ข้อมูลรหัสผ่านใหม่ที่แก้ไข
2. ข้อมูลบทบาทผู้ใช้ที่ปรับเปลี่ยน
3. คำสั่งลบข้อมูลบัญชีผู้ใช้
4. สถานะการเปลี่ยนรหัสผ่าน
5. ข้อมูลบันทึกกิจกรรมความปลอดภัย
6. ข้อมูลรายชื่อสมาชิกทั้งหมด
7. สถานะการจัดการสมาชิก
เริ่มกระบวนการ
ตรวจสอบคำสั่งที่ได้รับจากสมาชิกหรือผู้ดูแลระบบ
กรณีสมาชิกเปลี่ยนรหัสผ่าน: ตรวจสอบความถูกต้องของรหัสเดิม ส่งออก ข้อมูลรหัสผ่านใหม่ที่แก้ไข ไปยังแฟ้มข้อมูลผู้ใช้งาน และส่ง สถานะการเปลี่ยนรหัสผ่าน ให้สมาชิก
กรณีผู้ดูแลระบบค้นหาสมาชิก: ดึง ข้อมูลสมาชิกทั้งหมดในระบบ จากแฟ้มข้อมูลผู้ใช้งาน แล้วส่งออก ข้อมูลรายชื่อสมาชิกทั้งหมด
กรณีผู้ดูแลระบบปรับเปลี่ยนสิทธิ์: ส่งออก ข้อมูลบทบาทผู้ใช้ที่ปรับเปลี่ยน ไปยังแฟ้มข้อมูลผู้ใช้งาน
กรณีผู้ดูแลระบบลบบัญชี: ส่งออก คำสั่งลบข้อมูลบัญชีผู้ใช้ ไปยังแฟ้มข้อมูลผู้ใช้งาน และส่งออก สถานะการจัดการสมาชิก ให้ผู้ดูแลระบบ
ส่งออก ข้อมูลบันทึกกิจกรรมความปลอดภัย ไปยังแฟ้มข้อมูลบันทึกระบบทุกครั้งที่มีการเปลี่ยนแปลงข้อมูล
จบการทำงาน

ชื่อกระบวนการ(Name) : บริหารจัดการรายการหลักทรัพย์
ข้อมูลนำเข้า(Input data flow)
1. คำสั่งเพิ่มข้อมูลหุ้นใหม่
2. คำสั่งลบข้อมูลหุ้นออกจากระบบ
3. คำสั่งค้นหาข้อมูลหุ้น
4. ข้อมูลรายการหลักทรัพย์ในระบบ
ข้อมูลออก(Output data flow)
1. ข้อมูลหลักทรัพย์ใหม่
2. คำสั่งลบข้อมูลหลักทรัพย์
3. ข้อมูลบันทึกการจัดการตลาด
4. ข้อมูลรายการหุ้นในระบบ
5. สถานะการจัดการข้อมูลหุ้น
เริ่มกระบวนการ
รับคำสั่งจัดการข้อมูลหุ้นจากผู้ดูแลระบบ
กรณีค้นหาข้อมูลหุ้น: ดึง ข้อมูลรายการหลักทรัพย์ในระบบ จากแฟ้มข้อมูลหลักทรัพย์ แล้วส่งออก ข้อมูลรายการหุ้นในระบบ ให้ผู้ดูแลระบบ
กรณีเพิ่มข้อมูลหุ้นใหม่: ตรวจสอบความถูกต้อง ส่งออก ข้อมูลหลักทรัพย์ใหม่ ไปบันทึกในแฟ้มข้อมูลหลักทรัพย์
กรณีลบข้อมูลหุ้น: ส่งออก คำสั่งลบข้อมูลหลักทรัพย์ ไปยังแฟ้มข้อมูลหลักทรัพย์
ส่งออก สถานะการจัดการข้อมูลหุ้น รายงานผลให้ผู้ดูแลระบบทราบ
ส่งออก ข้อมูลบันทึกการจัดการตลาด ไปยังแฟ้มข้อมูลบันทึกระบบ

ID : 2.2
ชื่อกระบวนการ(Name) : ดึงข้อมูลราคาข่าวสารการเงิน
ข้อมูลนำเข้า(Input data flow)
1. ข้อมูลราคาหุ้นย้อนหลัง
2. ข้อมูลข่าวสารการเงินล่าสุด
3. คำสั่งดึงข้อมูลตลาดล่าสุด
4. ข้อมูลรายการหลักทรัพย์ในระบบ
ข้อมูลออก(Output data flow)
1. คำขอข้อมูลราคาหุ้นย้อนหลัง
2. คำขอข้อมูลข่าวสารการเงิน
3. ข้อมูลบันทึกการจัดการตลาด
4. ข้อมูลราคาตลาดที่บันทึกใหม่
5. ข้อมูลเนื้อหาข่าวสารที่บันทึกใหม่
เริ่มกระบวนการ
รับ คำสั่งดึงข้อมูลตลาดล่าสุด จากผู้ดูแลระบบ หรือกำหนดการอัตโนมัติของระบบ
ดึง ข้อมูลรายการหลักทรัพย์ในระบบ จากแฟ้มข้อมูลหลักทรัพย์เพื่อระบุหุ้นเป้าหมาย
ส่งออก คำขอข้อมูลราคาหุ้นย้อนหลัง และ คำขอข้อมูลข่าวสารการเงิน ไปยังระบบบริการภายนอก (ตลาดการเงินและสำนักข่าว)
รับ ข้อมูลราคาหุ้นย้อนหลัง และ ข้อมูลข่าวสารการเงินล่าสุด จากระบบบริการภายนอก
ตรวจสอบความครบถ้วนและปรับปรุงรูปแบบข้อมูล
ส่งออก ข้อมูลราคาตลาดที่บันทึกใหม่ ไปจัดเก็บยังแฟ้มข้อมูลราคาหุ้นย้อนหลัง
ส่งออก ข้อมูลเนื้อหาข่าวสารที่บันทึกใหม่ ไปจัดเก็บยังแฟ้มข้อมูลข่าวสารการเงิน
ส่งออก ข้อมูลบันทึกการจัดการตลาด ไปยังแฟ้มข้อมูลบันทึกระบบ
จบการทำงาน

ID : 3.1
ชื่อกระบวนการ(Name) : ประมวลผลแบบจำลองทำนายราคา
ข้อมูลนำเข้า(Input data flow)
1. คำสั่งประมวลผลการทำนายราคาทั้งหมด
2. ข้อมูลราคาล่าสุดสำหรับเทรนโมเดล
3. ข้อมูลราคาในอดีตสำหรับเทรนโมเดล
ข้อมูลออก(Output data flow)
1. ข้อมูลผลการทำนายราคาล่วงหน้า
2. ข้อมูลไฟล์แบบจำลองราคา
3. ข้อมูลบันทึกผลการประมวลผลโมเดล
เริ่มกระบวนการ
รับ คำสั่งประมวลผลการทำนายราคาทั้งหมด จากผู้ดูแลระบบ
